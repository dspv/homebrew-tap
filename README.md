# Caprock — Homebrew tap

Homebrew cask for [Caprock](https://caprock.dev) — mission control for Claude Code.

```bash
brew install dspv/tap/caprock
caprock up          # http://127.0.0.1:4173
```

The cask is published here automatically by [goreleaser](https://goreleaser.com)
when a `v*` tag is cut in [dspv/caprock](https://github.com/dspv/caprock). Do not
edit the cask by hand — it is generated.
